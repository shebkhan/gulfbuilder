## Brand & Style

This design system delivers a calm, high-trust, editorial environment tailored for GCC real estate investment, asset oversight, and portfolio management. The identity rejects cold enterprise-ERP conventions and aggressive saturated tech paradigms in favor of architectural quietude, understated prestige, and institutional clarity.

### Aesthetics & Philosophy
- **Editorial Architectural Poise:** Interfaces borrow visual pacing from high-end architectural monographs. Clean planes, deliberate white balance, and ample negative space allow complex yields, lease dates, and post-dated cheques (PDCs) to be surveyed without cognitive fatigue.
- **Warm Precision:** Monochromatic warmth grounds the interface, accented by subdued metallic warm gold to reflect regional distinction and asset value without vulgarity.
- **Quiet Authority:** Surfaces maintain physical lightness. Interaction states are delicate, tactile, and dignified, reinforcing fiduciary responsibility and long-term partnership.

## Colors

The palette relies on subtle surface gradations and restrained regional accents:

### Surfaces & Neutrals
- **Canvas Base:** `#F5F5F3` — Soft sand-linen foundation providing organic warmth beneath elevated layers.
- **Surface Crisp:** `#FFFFFF` — Primary content panels, cards, and active navigational tiers.
- **Surface Subtle:** `#FAFAF9` — Secondary sidebars, nested containers, and table row zebra-shading.
- **Surface Selected / Hover:** `#F1F1EF` — Active row selection, segment tabs, and hover states.
- **Hairline Borders:** `#ECECE9` (subtle internal dividers) and `#E2E2DE` (card perimeter and interactive borders).
- **Text & Ink:** 
  - Primary: `#1C1C1A` (deep warm charcoal, avoiding harsh pitch-black).
  - Secondary: `#666560` (fiduciary metadata and secondary body).
  - Muted / Placeholder: `#9E9D96` (inactive chevrons, timestamps, table column caps).

### Accents & Semantic Roles
- **Primary Prestige Gold:** `#C9A15A` | Soft tint: `#F6F0E5` (Active navigation indicators, portfolio summary progress rings, and key financial anchors).
- **Positive Yield / Settled:** `#4C9B72` | Soft tint: `#EAF4ED` (Collected rent, green yield variance, active tenant renewals).
- **Warning / Maturing:** `#C58B3B` | Soft tint: `#F8F0E3` (Cheques pending presentation within 7 days, expiring short-term leases).
- **Overdue / Risk:** `#C96A63` | Soft tint: `#F8ECEA` (Bounced PDCs, overdue maintenance, compliance flags).
- **Informational Slate:** `#7895A8` | Soft tint: `#EFF4F7` (Market intelligence, regional regulatory updates).

## Typography

The type system blends the quiet structural geometry of **Manrope** for numbers and display headers with the utilitarian legibility of **Inter** for dense transactional tables and operational microcopy.

### Rules & Formatting
- **Section Kickers & Overlines:** Rendered strictly uppercase with deliberate tracking (`0.12em`) using `section-kicker` (e.g., `PORTFOLIO YIELD`, `UPCOMING PDC CLEARANCE`, `DOHA RETAIL METRICS`).
- **Tabular Figures:** Always apply `font-variant-numeric: tabular-nums` to financial amounts, QAR currencies, floor areas (sqm), unit counts, and dates to ensure column vertical alignment.
- **Currency Styling:** Format currency notation gracefully (`QAR 1,240,000`). The ISO currency prefix or symbol is set at 80% opacity and 1px smaller than the tabular value.

## Layout & Spacing

The viewport architecture mirrors an expansive architectural frame:

### Master Framework & Reflow
- **Outer Shell:** In desktop viewports (1280px+), the main application interface is framed by a persistent, generous background padding (`margin: 2rem`), presenting the entire console inside a floating, rounded master canvas (`border-radius: 28px`) bordered with a crisp `1px solid #E2E2DE`.
- **Sidebar Integration:** A lean 260px white navigation sidebar sits flush to the left inside the master container, partitioned by a continuous vertical hairline border (`#ECECE9`).
- **12-Column Responsive Grid:** The main canvas employs a 12-column grid. KPI metric blocks comfortably span 3 columns each on desktop, collapsing to 6 columns on tablet (768px-1024px) and 12 columns full-width on mobile (<768px).
- **Mobile Collapse:** On mobile viewports, the master shell's 28px perimeter collapses to edge-to-edge flush margins with standard safe-area padding (`margin-mobile: 1rem`) and the sidebar transforms into a bottom utility sheet.

## Elevation & Depth

Visual hierarchy uses flat architectural planes, tonal layering, and fine-line geometry instead of deep multi-stage shadows.

- **Tonal Stacking:** Depth is achieved via `#F5F5F3` (canvas) -> `#FFFFFF` (card base) -> `#FAFAF9` (nested subsection/table header).
- **Hairline Outlines:** All cards and containers feature a single, high-precision `1px solid #ECECE9` border.
- **Ambient Diffusion:** When an element is raised (such as an active dropdown, modal, or floating card hover), use a singular, ultra-diffused, warm shadow:  
  `box-shadow: 0 12px 32px -8px rgba(28, 28, 26, 0.04), 0 4px 12px -4px rgba(28, 28, 26, 0.02)`.
- **Image Treatment:** Architectural photography cards utilize subtle bottom-edge gradient overlays (`linear-gradient(180deg, rgba(28,28,26,0) 40%, rgba(28,28,26,0.5) 100%)`) allowing crisp white data pills to float effortlessly over high-resolution imagery.

## Shapes

The interface balances soft geometry with rigorous corporate structure:

- **Master Application Enclosure:** `28px` corner radius on the primary desktop application viewport frame.
- **Cards, Panels & Data Tables:** `12px` to `16px` corner radii (`rounded-lg`).
- **Interactive Controls & Buttons:** Full pill-shaped rounding (`9999px`) on primary action buttons, search bars, filter chips, and status badges.
- **Nested Micro-Elements:** `6px` to `8px` corner radius (`rounded-md`) for input fields, checkbox controls, and thumbnail photo clips.

## Components

### 1. Primary & Secondary Buttons
- **Primary Action (CTA):** Full pill (`rounded-full`), `#C9A15A` background with crisp white `#FFFFFF` text. Micro-transition to `#B89047` on hover. Padding: `10px 24px`.
- **Secondary / Ghost:** Transparent background with `1px solid #E2E2DE` hairline border, `#1C1C1A` text. On hover, background shifts to `#F1F1EF`.
- **Destructive:** Soft crimson tint background `#F8ECEA` with `#C96A63` text, avoiding alarming saturated red blocks.

### 2. Metric KPI Cards & Sparklines
- **Container:** White surface, `1px solid #ECECE9` border, `16px` border radius, `space-lg` padding.
- **Composition:** Top row contains `section-kicker` label alongside an info popover icon; middle contains the tabular `metric-num` with currency marker; bottom contains a fine sparkline (1.5px stroke, `#C9A15A` or `#4C9B72`) paired with an understated trend chip (`+4.2% vs last quarter`).

### 3. Status Badges & Event Chips
- **Geometry:** Height 24px, pill-shaped (`border-radius: 9999px`), padding `2px 10px`.
- **Palette Variants:**
  - *Active / Cleared:* `#EAF4ED` background, `#4C9B72` label, `4px` solid green leading indicator dot.
  - *Cheque Pending / Due:* `#F8F0E3` background, `#C58B3B` label, amber leading dot.
  - *Overdue / Alert:* `#F8ECEA` background, `#C96A63` label, crimson leading dot.
  - *Draft / Neutral:* `#FAFAF9` background, `#666560` label, `1px solid #ECECE9`.

### 4. PDC Cheque & Lease Event Rows
- **List Item Structure:** Height 56px, horizontal layout, divided by hairline dividers `#ECECE9`.
- **Visuals:** Left icon container displays bank/cheque glyph with bank code (`QNB`, `CBQ`); middle displays issuer entity and maturity date; right features right-aligned tabular currency value (`metric-num-sm`) and clearance status badge.

### 5. Input Fields & Selectors
- **Input Styling:** Height 42px, `8px` corner radius, `#FFFFFF` surface with `1px solid #E2E2DE`. Font size 14px. Focus state transitions to `1px solid #C9A15A` accompanied by an ultra-soft gold ring `0 0 0 3px #F6F0E5`.
- **Search:** Pill-shaped search bar with muted search icon `#9E9D96` and keyboard shortcut cue (`⌘K`) in light grey.

### 6. Architectural Intelligence Cards
- **Structure:** Rounded `16px` card containing a 16:9 ratio architectural photograph with soft gradient blend at the base, overlaying property title, unit occupancy rate, and an elegant right-aligned ghost circle button with an arrow chevron.
