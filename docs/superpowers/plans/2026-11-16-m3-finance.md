# M3 Finance and Ledger Implementation Plan

**Goal:** Payments, receipts with gapless numbering, cheque management, security deposit lifecycle, expenses, double-entry ledger, and chart of accounts with Web UI.

**Architecture:**
- All financial state transitions, gapless receipt numbering, and journal postings live in atomic SQL RPC functions.
- Every business table has `org_id`, RLS enabled, and policies scoped by `auth_org()` / `auth_role()`.
- Immutable double-entry bookkeeping: `journals` and `journal_lines` cannot be updated or deleted; corrections are posted as reversing journals. Closed periods reject postings.
- Money is integer minor units plus currency code (`QAR`).

**Spec:** `docs/SPEC.md` §5.4, §5.6, §7.1, §7.4, §7.5, §7.7, §12 (M3), §13 (Criteria 4, 5, 7, 8).
